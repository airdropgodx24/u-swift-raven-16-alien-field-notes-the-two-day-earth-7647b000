# Alien Field Notes: The Two Day Earth Review

An entry for the make.fun competition "Alien Field Notes: The Two Day Earth Review".

The entry is one original line of plain text: a review of planet Earth left
by an alien tourist, written by a small Python program.

## How to run

```sh
python3 main.py
```

## Output

The program writes exactly one line of plain text (under 200 characters) to:

```
/output/entry.txt
```
